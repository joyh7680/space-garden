# 코스모 가든 · Cosmo Garden

귀여운 외계 생명체와 함께 꽃을 심고 자동 농장을 운영하는 브라우저 게임 프로토타입입니다. Vue 3 + TypeScript + Vite + Phaser 3로 구현했습니다. 제공받은 기획서는 원본 그대로 보존했습니다.

## 실행

Node.js 22.18 이상이 필요합니다. 최초 한 번 패키지를 설치하면 플레이 중에는 외부 API, 이미지 서버 또는 인터넷 연결이 필요하지 않습니다.

```powershell
cd C:\workspace\codmos-creator\cosmo-garden
npm install
npm run dev
```

터미널에 표시되는 주소(기본 `http://127.0.0.1:5173/`)를 브라우저에서 여세요. 포트가 사용 중이면 Vite가 다음 포트를 선택합니다.

```powershell
npm test          # 핵심 게임 규칙 테스트
npm run build    # TypeScript/Vue 검사 + 프로덕션 빌드
npm run preview  # dist 빌드 미리보기
```

## 처음 5분 플레이

1. 정거장 오른쪽 **정수 먹이기**를 2~3회 눌러 꽃잎을 얻습니다. 정수 1개 → 꽃잎 10개입니다.
2. **행성 탐험**에서 **꽃 심기 시작**을 누릅니다. WASD, 방향키, 화면 방향 패드 또는 지도 클릭으로 이동합니다.
3. 시작 지점 위쪽의 **별빛 목련** 점선 원 안에서 위 → 오른쪽 → 아래로 작은 사각형을 그리며 걸어보세요. 다른 위치에 꽃 20송이를 심으면 꽃이 피고 정수·씨앗·알을 받습니다. 이미 심은 칸은 꽃잎을 소비하지 않습니다.
4. **부화실**에서 알을 부화시키면 새로운 친구가 탐험팀에 합류합니다.
5. **스마트팜**에서 친구를 눌러 농사에 배치합니다. 기본 작물은 약 20초 만에 자동 수확됩니다. 다른 화면에서도 게임이 열려 있으면 농장은 작동합니다.
6. 별빛 결정 **8개**를 모아 **온실 확장**을 누르면 재배 구역이 2개에서 4개로, 친구 배치 한도가 2마리에서 4마리로 늘어납니다.

## 구현 기능

- 모모·루미·피피 3종의 오리지널 생명체, 대기·걷기·따라오기·먹이 반응
- 정거장, 스크롤 가능한 행성 탐험 맵, 스마트팜, 생명체 도감, 부화실
- 꽃 3색 선택, 타일 단위 중복 심기 방지, 꽃잎 소진 시 자동 중지
- 거대 식물 2개, 주변 20송이로 성장 단계 변화, 개화 연출과 1회 한정 보상
- 알 부화, 개체별 경험치와 레벨, 탐험팀/농장 상호 배타적 배치
- 작물 3종, 자동 심기·물 주기·성장·수확, 성장 외형과 작업 애니메이션
- 다음 작물 예약: 재배 중 품종을 바꾸면 현재 작물을 수확한 뒤 적용
- 친구 수에 따른 재배 속도 증가(최대 1.75배), 온실 확장 시 실제 공간 추가
- 5단계 미션, 보상 알림, 선택 가능한 효과음, 터치 조작과 반응형 UI
- localStorage 자동 저장 및 새로고침 복원, 잘못된 저장 데이터 복구, 설정 내 초기화

## 프로토타입 밸런스

| 항목 | 설정 |
| --- | --- |
| 시작 자원 | 생명체 3마리, 정수 6개, 꽃잎 0개, 씨앗 2개 |
| 먹이 | 정수 1개 → 꽃잎 10개, 경험치 12 |
| 개화 | 식물 주변 반경 290 안에 꽃 20송이 |
| 개화 보상 | 정수 3개, 씨앗 2개, 알 1개; 첫 개화 씨앗 1개 추가 |
| 글로우 베리 | 20초, 정수 2개 + 결정 2개 |
| 루나 플라워 | 첫 개화 해금, 30초, 꽃잎 12개 + 정수 1개 + 결정 3개 |
| 크리스탈 허브 | 수확 2회 해금, 40초, 정수 1개 + 결정 5개 |
| 재배 지속 | 재배마다 씨앗 1개 사용, 수확마다 씨앗 1개 반환 |
| 온실 확장 | 결정 8개, 재배 구역 +2, 친구 배치 한도 +2, 씨앗 +2 |

테스트 재현성을 위해 두 거대 식물 모두 첫 개화에 알을 확정 지급합니다. 개화 보상은 각 식물별 한 번만 받을 수 있습니다. 동료를 모두 농장에 배치해도 탐험가는 혼자 꽃을 심을 수 있습니다.

## 주요 구조

```text
src/
  App.vue                    화면 구성, 메뉴, 관리 UI, 보상/설정 모달
  style.css                  파스텔 UI, 태블릿·모바일 레이아웃, 애니메이션
  game/
    model.ts                 순수 게임 규칙, 자원 계산, 미션, 저장 검증
    store.ts                 Vue 공통 상태, 자동 재배 타이머, 알림, 저장
    GardenScene.ts           Phaser 맵, 오리지널 그래픽, 이동·동료·꽃·작업 연출
  components/
    GameCanvas.vue           Phaser 생명주기와 화면 크기 연동
    CreatureArt.vue          생명체 SVG 일러스트
    Icon.vue                 로컬 SVG UI 아이콘
tests/game.test.ts           자원·중복 보상·자동 재배·복원·전체 루프 테스트
public/favicon.svg          정원 파비콘
```

그래픽은 Phaser Graphics와 SVG로 직접 표현해 외부 에셋 의존성이 없습니다. 모든 자원 계산은 `game/model.ts`에서 수행하며 Vue UI와 Phaser가 같은 공통 상태를 사용합니다.

## 범위와 제한

- 로컬 브라우저 싱글플레이입니다. 로그인·서버·GPS·결제·멀티플레이는 없습니다.
- 탐험 가능한 행성은 1개입니다. 동굴은 배경으로만 표시합니다.
- 작물은 게임이 열린 동안만 성장합니다. 브라우저를 닫은 동안의 오프라인 생산은 계산하지 않습니다. 비활성 탭에서는 브라우저 타이머 제한으로 느려질 수 있습니다.
- 저장은 브라우저/주소별로 분리됩니다. 시크릿 모드, 저장 제한 또는 사이트 데이터 삭제 시 유지되지 않을 수 있습니다.
- 저장은 약 1초마다 및 페이지 종료 시 수행됩니다. 재배 진행 중인 작물과 다음 품종 예약도 저장됩니다.
- 탐험 지형은 경계만 제한하며 장식물 충돌·길찾기는 구현하지 않았습니다.
- 복잡한 진화·직업·희귀도·추가 행성·실제 동굴 탐험은 후속 범위입니다.

## 검증

`npm test`에서 시작 데이터, 먹이 자원 교환, 중복 꽃 방지, 반경 개화, 보상 중복 방지, 부화, 배치 한도, 자동 수확, 품종 예약, 희귀 작물, 확장 중복 방지, 저장 복원/오류 복구, 시작 자원으로 전체 루프 완주를 검증합니다.

`npm run build`에서 Vue/TypeScript 타입 검사와 Vite 프로덕션 빌드를 수행합니다.

실제 브라우저에서도 먹이 주기 → 터치 방향 패드 이동과 꽃 20송이 심기 → 개화 보상 → 알 부화 → 새 친구 농장 배치 → 자동 수확 → 작물 예약 → 온실 확장 → 새로고침 복원을 확인했습니다. 검증 중 브라우저 오류 로그는 없었습니다. 1280×800, 1024×768 태블릿 가로 화면과 390px 좁은 화면을 점검했으며, 1024px·390px에서 문서 가로 넘침이 없음을 확인했습니다.

검증 화면은 `artifacts/station-tablet.png`, `artifacts/smart-farm-tablet.png`에 저장했습니다. 브라우저 검증은 별도 포트 5174에서 수행했으므로 기본 포트 5173으로 실행하면 새로운 정원으로 시작합니다.
